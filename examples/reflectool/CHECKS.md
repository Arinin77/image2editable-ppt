# Editable reconstruction / 可编辑重建

- 150 native text objects; 17 editing groups; 23 independent picture instances.
- Region boundaries, highlights, arrow bands, candidate nodes and feedback curves are native PowerPoint objects. Routed paths use fixed geometry and need adjustment when modules move.
- The source was transcribed and its connections reviewed separately. All 56 source strings checked against the exported text were present, including visible source truncations.
- Microsoft PowerPoint checks: edit a label, move a group with its children, and move an independent picture. Changes were restored without saving the test state.
- Final native PowerPoint text-bound check: 0 width warnings. Whole-slide and verification-loop rendering reviewed; the overlapping `2-refine` label was repositioned.
- The public adaptation replaces one calculator icon with an Apache-2.0 website asset. Visible diagram text and relationships are preserved; the source image is unchanged.
- This is a curated conversion example, not a model benchmark or a pixel-perfect reproduction claim. Icons remain independently replaceable pictures rather than editable internal strokes.
